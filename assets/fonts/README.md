# Inter 4.1

Oryginalne, niezmodyfikowane webfonty projektu Rasmusa Anderssona:

- https://github.com/rsms/inter/blob/v4.1/docs/font-files/InterVariable.woff2
- https://github.com/rsms/inter/blob/v4.1/docs/font-files/InterVariable-Italic.woff2
- Licencja SIL Open Font License 1.1: `OFL-Inter.txt`.

Zmienne wagi 100–900, komplet znaków, w tym polskie. Normal jest wstępnie
ładowany przez HTML; italic jest pobierany dopiero wtedy, gdy wystąpi kursywa.
Źródło CSS: `styleguide/fonts.css`. Brak zależności od Google Fonts i fontów
zainstalowanych lokalnie u odwiedzającego.
